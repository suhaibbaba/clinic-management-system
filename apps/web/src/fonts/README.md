# Tajawal, with the app's vertical metrics

Google's Tajawal (SIL OFL 1.1, see `LICENSE`), taken from `@fontsource/tajawal` and modified in one
respect: `hhea` and `OS/2` carry an ascent of 780 and a descent of 220 per 1000 units, a zero line
gap, and the `USE_TYPO_METRICS` bit. Regenerate with `python3 scripts/patch-font-metrics.py`.
